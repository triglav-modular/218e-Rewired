218e V3 Rewired

Custom firmware builder for the Buchla 218e V3

⚠ READ THIS BEFORE YOU FLASH ANYTHING

This firmware is only for the Buchla 218e V3. It won't work on the 218, the 218r, the 218e v1 or v2, or any other touchplate controller.

Using this tool and firmware is entirely at your own risk. This is an experimental, unofficial firmware, not made or supported by Buchla. It also probably voids your warranty. It has been tested on one instrument. Recovering a bricked unit may need JTAG hardware and opening the instrument, or may not be possible at all.

A failed flash usually leaves the keyboard in DFU mode, where the flasher can try again, but there is no guarantee that it will succeed. If losing the use of your 218e would be a problem, stop here and keep the factory firmware.

Volts per octave

Corrects your 208's tracking per semitone, so the keyboard plays in tune across the whole range. Enter what your tuner reads in cents. Positive for sharp, negative for flat.

Correcting the tuning for one oscillator will make any other oscillator play more out of tune, so this is only recommended if the keyboard is only ever played with one 208.

How to measure your 208. Read this first!

1. Set the volts per octave. Match the setting above to how your 208 is trimmed, and leave it there. A table measured at one scaling is wrong at the other. Measure against equal temperament.

2. Warm up for at least 30 minutes. The oscillator drifts as it comes up to temperature, often by more than the error you are correcting.

3. Tune the lowest C. Octave switch at its lowest setting, hold the lowest C, and trim the 208 until a tuner reads it exactly in tune. Everything else is measured against this note.

4. Play every note, note how far off it is. Work up from that C, changing octave as you run out of keys. Enter the tuner reading in cents: +12 for 12 cents sharp, −7 for 7 flat.

5. Build, flash, check.

Alternate tunings

Three tuning tables, switched from edit mode. Each Scala file needs 12 degrees and a true 2/1 octave. Empty slots keep the factory temperament.

Each scale is shifted so A sits at the same pitch in every slot (the shift is shown per slot) so switching tuning never means retrimming the 208. Which degree lands on the bottom C is up to the file: a scale published rooted on A needs rotating first.

4 · Flash it

  1. Download the built package for your operating system.
  2. Connect the 218e, directly rather than through an unpowered hub:
    Standalone LEM218 — USB-C to the computer, power connected, switched on.
    218e module — USB-B from the 5xIO module that carries its USB and MIDI.
  3. Power on the 218e.
  4. Run the flasher and follow their instructions:
    macOS — double-click Program218e_v3_Rewired_macOS.command. The first time macOS refuses it, because a download is quarantined and this is unsigned: right-click, choose Open, confirm. Once only.
    Windows — double-click Program218e_v3_Rewired_Windows.bat

Your system might warn you about unsigned software

If macOS blocks the flasher, open System Settings → Privacy & Security and press Open Anyway.
Windows Defender may warn about the .bat: More info → Run anyway.

Windows only — the first flash pauses for a driver

Partway through the flash, the flasher will stop and open Zadig at the one moment it can see the device. Do the following steps in it:

  1. Options → List All Devices
  2. Select AT32UC3B DFU (03EB 2FF6)
  3. Set the right-hand box to WinUSB, press the Install Driver or Replace Driver button
  4. Close Zadig.
Oh no… something went wrong
The keyboard seems stuck with some LEDs on
Either run the programmer scripts again, or use the ExitDFU scripts to restart the instrument in regular mode.
macOS: ExitDFU_218e_v3_macOS.command
Windows: ExitDFU_218e_v3_Windows.bat
Every LED is lit and the keyboard does nothing
There is no valid firmware on it. An erase happened but the write did not finish. Try running the flasher again.
Windows: no device present, or Device Manager lists AT32UC3B DFU under Other devices
The WinUSB driver is not bound. Run Zadig as above. Installed correctly, the entry moves to Universal Serial Bus devices.
Windows: the 218e appears under Universal Serial Bus devices instead of Sound, video and game controllers
Windows has picked the wrong MIDI driver, so the DFU request never reaches the instrument. Right-click it, Update driver, choose manually, and pick USB Audio Device.
Windows: VCRUNTIME140_1.dll was not found, or a tool is “not recognized”
The Microsoft C++ runtime is missing. Install it from Microsoft's redistributable page, or from Buchla's kit.

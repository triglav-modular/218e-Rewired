6 · Flash

The instrument must be powered from a stable supply and connected by USB directly, not through an unpowered hub.


  
Programming is not done here.
  This page puts the instrument into DFU and inspects the bootloader, but it does not erase or
  write — that is left to the flasher for your platform, which verifies the checksum, confirms
  the bootloader region is protected, and validates by read-back before leaving DFU.
  


  macOS — put the built image in firmware/ and run
  ProgramLEM218_PressureFix.command. Needs Rosetta on Apple silicon,
  because dfu-programmer is x86_64 only.
  


  Windows — put the built image in firmware\ and run
  ProgramLEM218_PressureFix.bat. It uses the tools from Buchla's own
  windows\ kit, which is not redistributed here, and the DFU device
  needs the WinUSB driver installed once with the bundled Zadig.

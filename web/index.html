218e v3 Rewired — firmware builder

Builds custom v36.9 firmware for the Buchla 218e in your browser. Your firmware file never leaves this machine — there is no server.

⚠ READ THIS BEFORE YOU FLASH ANYTHING

This is only for the Buchla 218e version 3, running firmware v36.9. Not the 218, not the 218r, not the 218e v1 or v2, not any other touchplate controller. The build refuses any file that is not the exact v36.9 image.

You do this entirely at your own risk. This is experimental, unofficial firmware, not made or supported by Buchla. It has been tested on one instrument. It can brick your keyboard. Recovering a bricked unit may need JTAG hardware and opening the instrument, and may not be possible at all.

A failed flash usually leaves the keyboard in DFU mode, where the flasher can try again — but nobody is promising that. If losing the use of your 218e would be a problem, stop here and keep the factory firmware.

2 · Options

Volts per octave — 1.2 is the standard Buchla scaling and the normal choice. 1 V/oct is for other gear. Either way the 208 needs retrimming after a change.

3 · Alternate tunings optional

Up to three Scala files, switchable from edit mode. Each needs 12 degrees and a true 2/1 octave. Leave empty to keep the factory temperament.

none

4 · Per-key pitch correction optional

Corrects your 208's pitch tracking per semitone, so the keyboard plays in tune across its whole range. The correction belongs to your oscillator at your volts-per-octave setting — there is no useful default, which is why this starts empty. Enter what your tuner reads: how many cents sharp each note played, positive for sharp and negative for flat. The builder works out the correction from that — do not negate anything yourself. Leave everything at zero for an uncorrected ramp.

How to measure your 208 — read this first

1. Set the volts per octave first. Pick the setting above that matches how your 208 is trimmed — 1.2 for the standard Buchla scaling, 1 V/oct if you have trimmed it that way — and do not change it afterwards. The tracking error you are about to measure belongs to that setting; measure at one scaling and use the table at the other and the correction will be wrong.

2. Let it warm up. Power the 208 on and leave it for at least 30 minutes. The oscillator drifts as it comes up to temperature, and a table measured cold will be wrong once it settles — often by more than the error you are trying to correct.

3. Tune the lowest C perfectly. With the octave switch at its lowest setting, hold the lowest C on the keyboard and trim the 208 until a tuner reads it exactly in tune. Everything after this is measured relative to that note, so if it drifts, the whole table shifts with it.

4. Play every note and write down how far off it is. Work up from that lowest C, one note at a time, then change octave and keep going until you run out of range. For each one, note what the tuner says in cents from the correct pitch — +12 if it plays 12 cents sharp, −7 if it plays 7 cents flat. Enter those numbers, not the pitch you wanted.

5. Build, flash, and check. Play back through the keyboard with a tuner. Nothing accumulates: each box is simply what that note measured, so if you want to redo the measurement, disable the correction, measure again from scratch, and type the new readings in.

Measure against equal temperament. If you have an alternate tuning loaded, its own intervals will read as error. Use 12-TET, or no alternate tuning at all, while measuring.

6 · Flash it

Flashing is done by the script for your platform, not by this page. Each one verifies the image checksum, confirms the bootloader region is protected, and validates by read-back before letting the instrument leave DFU.

  1. Download the image above — leaving it in your Downloads folder is fine.
  2. Connect the 218e by USB, directly rather than through an unpowered hub, on stable power.
  3. Run the flasher and follow it:
    macOS — double-click Program218e_v3_Rewired.command
    Windows — double-click Program218e_v3_Rewired.bat
The flasher finds the image itself. It looks in firmware/, beside itself, and in your Downloads folder, and takes whichever file matches the checksum it expects — so there is nothing to move or rename.
Platform notes

macOS needs Rosetta on Apple silicon, because dfu-programmer is x86_64 only: softwareupdate --install-rosetta.

Windows uses the tools from Buchla's own windows\ kit, which is not redistributed here. The DFU device needs the WinUSB driver installed once, with the Zadig executable that kit bundles.
